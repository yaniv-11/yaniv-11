##  CityInfo-GraphRAG

**Python · LangChain · Gemini · ChromaDB · BM25 · Knowledge Graph · RAG**

A multimodal GraphRAG system for retrieving structured and unstructured information from government documents.

* Built a multimodal ingestion pipeline for government PDFs.
* Combined **PDF text extraction with Gemini vision-based image captioning**.
* Extracted **1,498 subject–relation–object knowledge triplets** to construct a knowledge graph.
* Implemented hybrid retrieval combining **BM25 lexical search with dense vector retrieval**.
* Injected entity-matched graph context alongside retrieved document chunks for richer answers.

##  Automated Leukemia Detection

**TensorFlow · EfficientNetB3 · ResNet152V2 · ConvNeXtTiny · Computer Vision · Streamlit**

A deep learning system for automated classification of healthy and leukemic blood smear images.

* Built an ensemble architecture combining **EfficientNetB3, ResNet152V2 and ConvNeXtTiny**.
* Combined extracted representations into a **4,352-dimensional feature vector**.
* Applied selective fine-tuning with ImageNet-pretrained backbones.
* Achieved **0.98 validation AUC** on a 10,000-image blood smear dataset.
* Deployed the inference pipeline as a **Streamlit application on Hugging Face Spaces**.

**[→ View Code](https://github.com/yaniv-11/Automated-Leukemia-Diagnosis) · [→ Live Demo](https://huggingface.co/spaces/Vinay-11/Leukemia-Analysis)**
